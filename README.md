

A single repository containing real-world security labs designed to demonstrate practical skills used by security analysts, pentesters, and contractor-based testers.

Each lab is scoped, ethical, and documented with clear findings.

---

🎯 What This Shows

- Hands-on security testing (not theory)
- Ability to follow scope and methodology
- Clear written communication
- Realistic security workflows

---

🧪 Lab Format (Consistent Across All Labs)

Each lab includes:
- Objective
- Scope
- Tools used
- Findings
- Artifacts
- Short written deliverable
